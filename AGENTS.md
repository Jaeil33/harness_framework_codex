# Repository instructions

Read `agent.md` in this repository before working. It is the canonical project guidance.

For a request to plan or execute a harness phase, read `skills/harness/SKILL.md`.
For a request to review a harness change, read `skills/harness-review/SKILL.md`.
These files also work before optional native skill registration has been installed.

Paths in these documents are relative to the repository root.
